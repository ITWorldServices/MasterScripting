
This excel sheet has a VBA routing attached. 
The routing will look in a specified folder for extracted permissions lists in xlsx format. 
A sample list is in this folder called sample.xlsx

Place your extracted permissions all in one folder.

I highly recommend that you do not try to process over 2000 lines of folders per sheet for permissions. This can take a very long time to turn into a grid. 

Change the name in the VBA script for the path that you have your excel sheets in. 

Currently it searches C:\MasterExports folder for excel files.
